# Complete Serveekay project

This archive contains the redesigned source, all local images and fonts, package lockfiles, configuration, and documentation.

## Start locally

Use Node.js 20.9 or newer. From this directory:

```bash
npm ci
npm run dev
```

Open http://localhost:3000. For production: `npm run build` then `npm start`.

See README.md and CUSTOMIZATION.md for the project structure, content, forms, and assets.

Git history, installed dependencies, generated build caches, and sandbox credentials are excluded. No application credentials are required. Contact forms open email drafts.
